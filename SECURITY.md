# Security Policy

## Supported Branch

Security fixes are applied to the active `main` branch only.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately by email to: `sebas1705@gmail.com`

Include:
- Affected area or module
- Reproduction steps
- Impact assessment
- Optional mitigation ideas

## Response Targets

| Stage | Target |
|---|---|
| Initial acknowledgement | ≤ 2 business days |
| Triage and severity classification | ≤ 5 business days |
| Fix plan shared | After triage completes |

## Disclosure

After a fix is released, coordinated disclosure is welcome.
